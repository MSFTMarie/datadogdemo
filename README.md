# Vercel + Datadog Demo

A beginner-friendly demo app to show a Vercel or Datadog hiring manager.

What it proves:
- Deployed a Next.js app on Vercel
- Added Vercel environment variables
- Sent browser logs to Datadog
- Searched logs by service name in Datadog

## Environment variables in Vercel

NEXT_PUBLIC_DATADOG_CLIENT_TOKEN=your_datadog_client_token
NEXT_PUBLIC_DATADOG_SITE=datadoghq.com

Use datadoghq.eu instead if your Datadog account is EU.
